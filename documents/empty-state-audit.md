# 小程序空状态全量清单

审计日期：2026-08-04

## 状态规则

- 只有网络、接口、权限或服务异常使用错误状态，并提供重试。
- 缺少账户、球队、球员等前置条件使用引导型空状态，并提供明确下一步。
- 赛季未开始、本轮尚未产出、当天没有变化属于正常空状态，不使用红色错误提示。
- 搜索或筛选无结果说明当前条件，并提供清除条件的操作。
- 纯导航页和表单页没有远程数据列表，不额外制造空状态。

## 19 个注册页面

|---|---|---|---|

| 10 | `pages/data/players/players` | 球员名单未同步；搜索无结果 | 区分源数据为空与搜索为空；提供重新加载或清除搜索 |

| 15 | `pages/data/selections/selections` | 未关联账户；没有联赛；各趋势尚未产出 | 账户/联赛使用引导型空状态；选择率、队长和转会按当前标签解释 |
| 16 | `pages/summary/entry/entry` | 未关联账户；GW 总结未生成；阵容、转会、开卡或历史为空 | 页面级前置条件与分标签空状态分别处理 |
| 17 | `pages/summary/tournament/tournament` | 未关联账户；没有联赛；总览、排名或累计指标未生成 | 使用账户/联赛引导，并按当前标签提供重新加载 |
| 18 | `pages/summary/gameweek/gameweek` | 总览或梦之队未生成；没有 10+ 分球员；无转会趋势 | 正常空状态带 GW 语境；四个并行接口的真实失败不再伪装成“暂无” |
| 19 | `pages/performance/index/index` | 尚无性能样本；尚无 API 请求样本 | 首次使用说明如何产生样本，保留运行环境信息 |

## 共享组件

- `app-empty-state`：统一插画、标题、解释、行动按钮，并支持重点引导卡。
- `app-error-state`：统一真实失败的视觉、解释和重试入口，避免页面中央只出现一行红字。
